# My Job Tracker

A lightweight, persistent React application designed to help job seekers organize their applications.


## Tech Stack

- **Framework**: React 19 (Functional Components)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Hooks**: `useState`, `useEffect`

## Installation & Setup

   ```bash
   git clone https://github.com/geraldine1989/job-tracker.git
   
   npm install

   npm run dev
